# 🍽️ HEMA - Smart Restaurant Management & QR System
*(Hotel & Environmental Management Application)*

An end-to-end, real-time smart restaurant management platform designed to eliminate order delays, paper KOT chaos, and floor bottlenecks.

---

## 🌟 Key Features

- 📱 **Zero-App Customer Ordering:** Table-top QR code scan opens a sleek web menu (PWA) with synchronized multi-guest cart.
- 🍳 **Real-Time Kitchen Display System (KDS):** Live order ticket cards with item-level status updates (`COOKING` ➔ `READY`) and cross-platform audio chime alerts.
- 🛎️ **Waiter Companion App:** Interactive floor map showing real-time table statuses (Free, Dining, Ready, Bill) and instant service request alerts.
- 💳 **Digital Billing & Checkout:** GST-compliant sequential invoice generation, integer paise arithmetic (zero float errors), CCPA-compliant voluntary service charge, and Staff-verified Cash & UPI payments.
- 📊 **Manager Operations Dashboard:** Live revenue tracking, active dining table metrics, and payment method breakdowns.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js 14+ (App Router), React, Tailwind CSS, shadcn/ui, Lucide Icons
- **Backend & Database:** Supabase (PostgreSQL, Supabase Realtime, Row Level Security, Storage)
- **State Management:** Zustand & TanStack React Query
- **Alerts:** HTML5 Web Audio API (Chime)
- **Financial Calculations:** Integer Paise (zero rounding bugs)
